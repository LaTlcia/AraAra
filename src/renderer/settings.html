对话

使用 OpenAI 兼容的 Chat Completions 接口（DeepSeek、通义千问、Ollama、各种中转都可以）。人格来自角色卡（含世界书），AI 回复里的情绪标签会驱动表情和动作。

外观

形态

Q 版自主活动

会做的事

还没到开始时间时她会安静待着，偶尔看看四周。打瞌睡只在深夜或者很久没人理她时出现，点她一下就会醒。

操作

  • 点头 = 摸头，点脸 = 戳脸，在头上来回晃鼠标 = 一直摸
  • 按住拖动可以把她搬到别处；Q 版放在半空会掉下来（可以关掉）
  • 双击或 Ctrl/⌘+Shift+Y 打开对话框，点 × 或按 Esc 收起；输入 /reset 清空记忆
  • 鼠标移到她身上会出现「说话 / 换衣服 / 菜单」按钮；右键也能打开菜单
  • 透明的地方鼠标会穿透，不影响你点后面的窗口

情绪接口

本地 HTTP 接口，可以让别的程序（脚本、机器人、Claude Code 的 hook 等）驱动亚罗椰的表情、动作和台词。只监听 127.0.0.1。
